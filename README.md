# Repetition Review Obsidian Plugin

This plugin shows notes that should be repeated based on a chosen tag and repetition schedule. Files are grouped into categories that correspond to days between reviews.

## Installation

1. Run `npm run build` to compile the plugin (requires Node and TypeScript).
2. Copy `manifest.json`, `dist/main.js` and `styles.css` (if you add styles) to your Obsidian plugin folder.

## Features

- Customizable tag for marking notes to review.
- Editable categories with a name and number of days.
- Command **Open Repetition Review** opens a side view listing due notes by category.

## Settings

Open the plugin settings to:

- Change the tag used to find notes.
- Add or remove categories and set the number of days for each.
